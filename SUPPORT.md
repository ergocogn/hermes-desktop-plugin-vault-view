# Support

Vault View support is handled through the GitHub repository.

## Questions and bug reports

- Search existing [GitHub Issues](https://github.com/ergocogn/hermes-desktop-plugin-vault-view/issues) first.
- Open a bug report for reproducible failures or regressions.
- Open a feature request for proposed behavior changes.

Include the Vault View and Hermes Desktop versions, operating system, Hermes backend environment, theme, reproduction steps, and expected and actual behavior. Remove vault paths, note contents, environment values, credentials, tokens, and client data from screenshots and logs.

## Security issues

Do not report security vulnerabilities in a public issue. Follow [SECURITY.md](SECURITY.md) instead.

## Scope

Vault View is an independent community project. Support for Obsidian or Hermes themselves must be requested from their respective maintainers.
